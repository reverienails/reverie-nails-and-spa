HOW TO UPDATE CURRENT SPECIALS

specials-data.js controls which special shows.
Set "current" to the key you want (happyHour, pumpkinSpice, giveaway, basic, july4).

Each special has:
- title and description
- image, imageWidth, imageHeight (a file in assets/img/)
- imageFit: "contain" when the whole poster should show

To change the art, put a new WebP in assets/img/ and point that special's image at it.
The page does not look for other filenames.
